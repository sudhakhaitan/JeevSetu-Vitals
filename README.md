# JeevSetu Examination — Stage B — General Examination

This is the first prototype of the separate clinical examination repository.

## Design
- Separate from the final History Taking Sections 1–21 repository.
- Separate from the completed JeevSetu-vitals Stage A repository.
- Intended for findings obtained by a nurse/ANM, doctor, or other qualified examiner.
- Structured fields are provided for common general-examination observations.
- A voice-first free-text examination note is provided so the examiner can speak findings instead of typing them.
- Voice capture uses the browser SpeechRecognition/Web Speech API and is currently set to Hindi (`hi-IN`).
- The captured speech is transcribed into the examination record; it does not generate a diagnosis.
- No clinical interpretation or diagnosis is generated by this Stage B prototype.
- The print view is a compact clinician summary.

## Source framework
The module follows the uploaded Section 19 physical-examination framework, particularly the General Physical Examination section, which includes general appearance, consciousness, distress, nutritional status, hydration, pallor, jaundice/icterus, cyanosis, clubbing, oedema, lymphadenopathy and other significant abnormalities.
