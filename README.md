# JeevSetu — Diabetic Foot Module

This is a standalone GitHub Pages module containing:

- A fillable Diabetic Foot assessment form.
- Examiner-editable four-view foot diagrams.
- A generated Diabetic Foot Clinical Note.
- A print button that prints only the clinical note.
- No endocrine or thyroid fields.

The module is intentionally separated from the Endocrine / Metabolic module.

Open `index.html` directly or publish the folder with GitHub Pages.
