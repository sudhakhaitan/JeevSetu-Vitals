# JeevSetu-Vitals — Stage A

## Purpose
A separate prototype repository for the Nurse/ANM first-visit measurement stage of JeevSetu.

## Stage A scope
- Patient ID
- Person performing measurement
- Blood pressure — both arms
- BP cuff size, device, position and time
- Ankle-brachial index (ABI) input fields
- Pulse
- Respiratory rate
- SpO2
- Temperature and unit
- Pain score
- Height
- Weight
- Automatically calculated BMI
- Waist circumference
- Hip circumference where appropriate
- Review and local save

## Important
This prototype is based on the supplied Section 19 document. It does not diagnose or interpret clinical findings.

ABI calculation/interpretation is deliberately not hard-coded yet because the supplied document specifies the measurements and automatic calculation but does not state the centre's final calculation/interpretation protocol.

## GitHub deployment
Upload `index.html` and this README to a new repository named:

JeevSetu-vitals

Then enable GitHub Pages from the repository's Settings > Pages, using the main branch and root folder.

The history-taking repository is not modified by this Stage A repository.
