# JeevSetu — Diabetic Foot Clinical Note

This package contains the cleaned, compact one-page Diabetic Foot Clinical Note.

## Files

- `index.html` — GitHub Pages entry page.
- `JeevSetu_Diabetic_Foot_Clinical_Note.pdf` — One-page clinical note with four foot diagrams.
- `README.md` — Package instructions.

## GitHub Pages

Upload all files in this folder to a GitHub repository.

Enable **Settings → Pages → Deploy from branch** and select the branch/root folder.

The published page will open `index.html` and provide the clinical-note PDF.

## Included diagrams

- Right Dorsal
- Right Plantar
- Left Dorsal
- Left Plantar
