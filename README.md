# JeevSetu — Genitourinary / Urinary & Female Preventive Screen

This ZIP contains the standalone Genitourinary module.

- Universal urinary symptom screen
- Female preventive screen without duplicating Section 16 reproductive history
- Consent/chaperone/examiner/date-time
- Indication-based urinary, male and female examination
- Prostate examination only when clinically appropriate
- Breast examination intentionally excluded; Section 19.19 handles it
- Print CSS hides the form and prints the clinical note as a compact A4 portrait page
