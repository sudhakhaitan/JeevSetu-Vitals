# JeevSetu — Endocrine / Metabolic Module

This is a standalone GitHub Pages module containing:

- A fillable Endocrine / Metabolic form.
- A generated Endocrine / Metabolic Clinical Note.
- A print button that prints only the clinical note.
- No diabetic-foot fields or diagrams.

Open `index.html` directly or publish the folder with GitHub Pages.

The field structure follows the supplied Endocrine / Metabolic clinical note.
