JeevSetu AI — Integrated Physical Examination with Neurological Examination

Open index.html in a modern browser or host the package on GitHub Pages. Patient details are entered once at the beginning. Modules included: Vitals, General/Functional Examination, Lymph Nodes, CVS, Respiratory, Abdominal/GI, and Neurological Examination.

No consolidated clinical note is generated by this package. The neurological module has no clinical-note generation or print-note screen. Neurological drafts are saved locally in the browser.
