JeevSetu Integrated Examination Package
Includes:
- Endocrine / Metabolic Examination
- Urinary Examination
- Male Genital Examination
- Female Genital & Breast Examination
- ENT History & Examination
- Eyes & Vision Examination
- Combined Clinical Note

GitHub upload:
1. Extract this ZIP.
2. Upload only index.html and README.txt to the repository root (2 files).
3. Use the same browser and device for all modules.
4. Generate the clinical note in each module, then open Combined Note and press Refresh Notes.
5. Eye examination findings and the Eye Finding Map are saved locally and included in the Combined Clinical Note.
Notes are stored in browser localStorage; do not clear browser data between examinations.
