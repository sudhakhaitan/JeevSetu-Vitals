JeevSetu Integrated Physical Examination — Vitals + General Examination + Lymph Nodes

This build adds a top-level Generate Clinical Note and Generate & Print Note action.
Enter patient details once, complete any available examination modules, then generate
and review the consolidated note. The note collects non-empty field entries from the
embedded modules and includes patient details. This is a prototype; review all generated
content for completeness and clinical accuracy before clinical use.

Open index.html in Chrome. No server is required.
