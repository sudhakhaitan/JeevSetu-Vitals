JeevSetu — Integrated Vitals, General Examination & Lymph Node Examination (Multiple Sites)

This corrected build supports multiple enlarged/palpable lymph-node sites, including saving a site when the corresponding regional screen is marked “Node/lump felt” even if exact location/size is not yet entered. Record each site separately using “Add this node site”; each entry includes region, side, exact location, size, consistency, mobility, tenderness, skin over node, and site-specific remarks. All entries are included in the consolidated clinical note and saved/loaded locally with the rest of the form.

Test: Extract the ZIP and open index.html in Chrome. Enter vitals and examination findings, add two or more lymph-node sites, generate the consolidated clinical note, and print/save PDF. Confirm each site appears separately in the note and that ABI, BMI and WHR calculations still work.

Clinical safety: This is a recording aid, not a diagnostic tool. Normal accessible-node findings do not exclude deep-node disease, tuberculosis or malignancy. Review findings with a qualified clinician before field deployment.
