JeevSetu AI — Lymph Node Examination (Dedicated Module)

CONTENTS
- index.html: self-contained browser module; no internet connection or external library required.

HOW TO TEST
1. Extract the ZIP archive.
2. Open index.html in Chrome.
3. Examine each region and enter findings. Region-specific details appear when “Node or lump felt” is selected.
4. Use “Save on this device” to save to this browser's local storage, “Load saved examination” to retrieve it, or “Export JSON” to download a data file.
5. “Print examination record” prints the question-wise record. This module does not generate the final consolidated clinical note.

IMPORTANT
- This is an examination-recording aid, not a diagnostic tool.
- A normal accessible-node examination does not exclude deep lymph-node disease, tuberculosis, or malignancy.
- Red/amber/green flags are prompts for clinical review, not diagnoses. Emergency triage takes precedence for severe illness.
- Local browser storage is device/browser-specific. Do not rely on it as a central medical record; follow approved privacy and data-handling procedures.
- The clinical protocol, diagrams, and referral thresholds should be reviewed by a qualified clinician before field deployment.
