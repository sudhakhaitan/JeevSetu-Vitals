JeevSetu Endocrine + Diabetic Foot — corrected integration

Changes:
1. Endocrine / Metabolic Clinical Note is separate and contains only endocrine/metabolic and thyroid findings.
2. Diabetic-foot drawings are removed from the endocrine note.
3. Diabetic Foot Clinical Note is compact and designed to print as a single A4 page, including four foot drawings.
4. Four interactive foot drawings are now part of the examiner input form: Right dorsal, Right plantar, Left dorsal, Left plantar.
5. Examiner selects a finding and taps/clicks the relevant area of a foot drawing to place a numbered marker. Tapping the same marked area again removes that marker.
6. The marked findings are automatically carried into the generated diabetic-foot clinical note, both as mapped text and as numbered markers on the four drawings.
7. Diabetic-foot note is generated only when the patient is marked diabetic.
