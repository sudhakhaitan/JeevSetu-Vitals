JeevSetu — 19.17 Vascular / Peripheral Circulation Examination
MULTI-LIMB REVISION

Limb selection:
- None
- Right upper limb
- Left upper limb
- Right lower limb
- Left lower limb

Multiple limbs can be selected simultaneously. “None” is exclusive.

Each selected lower limb receives its own venous examination block:
- Varicose veins
- Exact site when present
- Pigmentation
- Venous eczema
- Chronic venous changes
- Venous ulcer
- Exact ulcer site when present

The clinical note reports findings separately for each selected lower limb.
