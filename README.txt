JeevSetu — 19.17 Vascular / Peripheral Circulation Examination
GITHUB READY — REVISED

Changes in this revision:
- Limb inspection and venous/varicose assessment are grouped into one section.
- The examiner first identifies ALL affected limbs.
- Multiple limbs can be selected at the same time.
- Limb choices are exactly: None, Right upper limb, Left upper limb, Right lower limb, Left lower limb.
- If “None” is selected, other limb choices are cleared.
- Varicose veins are recorded within the same limb assessment.
- When varicose veins are present, exact site(s) can be recorded separately for each affected limb.
- Ulcer site and size/appearance are recorded together.
- Clinical Note now lists all selected affected limbs and the corresponding vascular/venous findings.
- Existing bilateral pulse, ABI, BP, arterial symptoms and bleeding-history logic is retained.
