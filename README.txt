JeevSetu — Combined Physical Examination Modules — FORMAT CORRECTED v5

This package preserves the working Vitals-to-Musculoskeletal consolidated note, respiratory chest maps, abdominal map, and combined-note storage behavior from v4 while applying the next set of requested refinements:

1. Endocrine: glucose reading types can be multi-selected; separate fields for fasting and post-prandial values, plus random/other value and date/time.
2. Urinary: unchanged.
3. Male/Female genital: combined note suppresses the opposite-sex genital section when sex can be identified from the integrated Vitals record or consolidated note.
4. ENT: explicit side selection for ear and nostril/nasal passage findings; smaller head/neck map in the clinical note to reduce wasted print space.
5. Eye: explicit side selection for routine screen, external appearance, anterior examination, and posterior examination; side appears in the generated note.
6. Dental: suppresses repeated patient ID/age lines in the combined note.
7. Skin: reduced body-map size on screen, standalone print, and combined note.
8. Vascular: attempts to prefill bilateral BP, ABI and bilateral peripheral pulse grades from saved integrated Vitals/CVS data; falls back to values in the latest generated Vitals note for BP/ABI when possible.

Use the same browser and device for all modules. After updating examination entries, generate each module's clinical note, open Combined Note, select Refresh Notes, then print/save the combined PDF.

ENT update: independent right/left ear and nostril examination fields; compact head/neck map in printed note; patient-entry form remains hidden when printing, with patient details retained in the clinical-note header.


Version v8 update: Eye module headings and generated clinical note no longer display unwanted section numbers 18.12 and 19.13. Eye Finding Map and existing right/left-specific fields are preserved.
