JeevSetu AI — Endocrine Examination
Standalone prototype ZIP for local browser testing or GitHub Pages.

Files:
- index.html: self-contained examination module; no external libraries required
- README.txt: this file

Included:
- Immediate warning screen that locks routine examination when a warning is selected
- Symptom screening for diabetes, thyroid and other endocrine-related concerns
- General endocrine examination and detailed thyroid/neck examination
- Fields for available glucose, HbA1c, thyroid hormone and other investigation results
- Local browser draft save/restore and browser print function

Excluded by design:
- Patient demographic entry (use the integrated patient details workflow)
- Diabetic Foot Examination (separate module)
- Automatic clinical-note generation, diagnosis or treatment recommendation

Safety note: prototype for trained examiners and appropriate clinical workflows. A selected warning sign should prompt urgent assessment according to local protocol; do not delay emergency care to complete the form. Browser storage is not a secure medical record system.
