JeevSetu – General Examination Module
========================================

Standalone module for:
18.1 General / Constitutional
19.2 General Examination
19.3 Lymph Node Examination
19.4 General Functional Assessment
19.5 Digital Body Map

Design:
- Stage A: general questions for every patient.
- Stage B: clinician examination and focused findings.
- Positive findings trigger a focused pathway; this module does not generate a Master Clinical Note.
- Data can be exported as JSON for later integration.
- Final Master Clinical Note must remain outside this module and be generated only after completion of Section 21.
