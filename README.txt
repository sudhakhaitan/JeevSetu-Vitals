JeevSetu AI — Integrated Physical Examination

This build updates consolidated-note collection to recognize additional module note/summary containers (including ENT, Eye, Dental, Neurological, Endocrine, Musculoskeletal, Skin, and vascular modules). It also collects note content even when the module note is hidden in the examination UI for print-control purposes. The consolidated note remains the intended print output; individual examination forms are not intended to be printed.

Test workflow:
1. Open index.html in Chrome.
2. Enter patient details once.
3. Complete and generate concise notes for Vitals, General Examination, and CVS first.
4. Tap Generate Final Clinical Note and confirm all completed systems appear.
5. Tap Print / Save PDF and confirm only the consolidated note prints.
