JeevSetu — Musculoskeletal Module
=================================

Module:
18.7 — MUSCULOSKELETAL
19.10 — MUSCULOSKELETAL EXAMINATION

Purpose
-------
This standalone module records musculoskeletal symptoms, focused functional/senior
assessment, bone-health risk factors, examination findings, pain-map information,
and musculoskeletal red flags.

Included
--------
1. 18.7 Musculoskeletal symptom screening
2. Functional / senior pathway
3. Bone-health screening where appropriate
4. Musculoskeletal examination
5. Relevant-joint examination
6. Spine examination
7. Right/left muscle-strength recording
8. Senior functional assessment
9. Pain-map information
10. Musculoskeletal red-flag alerts
11. Readable clinical-note generation
12. Print function that prints the clinical note only

Important design points
-----------------------
- Fall information is referenced from Section 9 and is not duplicated here.
- Red flags generate a clinician alert.
- The final clinical note is organized with clear headings and tables for easy
  clinical review.
- This is a standalone module intended for GitHub Pages testing.

Files
-----
index.html   Main JeevSetu Musculoskeletal module
README.txt   Module description and usage notes

Usage
-----
Upload the contents of this ZIP to the intended GitHub Pages repository.
Open index.html through GitHub Pages.
Complete the form and select "Generate Clinical Note".
Use "Print Clinical Note" to print only the clinical note.
