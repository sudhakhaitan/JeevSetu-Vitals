JeevSetu Vitals 2 — Integrated Build 2
Contents: index.html and README.txt only.

Includes Endocrine/Metabolic, Urinary, Male Genital examination modules and Combined Clinical Note inside one HTML file to reduce GitHub upload file count.

Use:
1. Upload index.html and README.txt to the same GitHub Pages folder.
2. Open index.html.
3. Complete each module and press Generate Clinical Note.
4. Open Combined Note and press Refresh Notes.
5. Use the same browser/device for all modules; notes are stored in browser localStorage.

Please test all three individual notes and the combined report before adding the next system.
