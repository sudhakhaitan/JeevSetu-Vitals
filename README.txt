JeevSetu Integrated Examination Package

Includes existing integrated modules: Endocrine, Urinary, Male Genital, Female Genital & Breast, ENT, Eyes & Vision, Dental / Oral, and Combined Clinical Note.

Upload index.html to GitHub Pages. Use the same browser and device for all modules. Generate the clinical note in each module, then open Combined Note and select Refresh Notes. Dental notes are stored in browser localStorage and included in the combined note.
