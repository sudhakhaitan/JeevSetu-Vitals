-------
This is a standalone JeevSetu Skin module for testing before integration
into the main JeevSetu examination sequence.

1. index.html
   The complete interactive Skin History + Skin Examination form.

2. README_SKIN_EXAMINATION.txt
   This file.

HISTORY — 18.10
----------------
Every patient:
- New skin change
- Mole / old lesion change
- Non-healing wound
- Itching / rash

Senior / diabetes / vascular risk:
- Foot/sole wound, blister, colour change or slow-healing cut

EXAMINATION — 19.15
-------------------
General skin examination:
- Pallor
- Jaundice
- Cyanosis
- Petechiae
- Purpura
- Ecchymosis / bruising
- Rash
- Pigmentation changes
- Ulcers
- Nodules / masses
- Other significant lesions

Petechiae / bleeding assessment:
- Site / distribution
- Localized / generalized
- Extent
- Mucosal bleeding
- Fever / systemic symptoms
- Relevant medications
- Known blood disorders

Mole / pigmented lesion:
- Site
- Size
- Colour
- Shape
- Border
- Symmetry
- Surface
- Bleeding
- Ulceration
- Reported change

Non-healing wound:
- Site
- Size
- Depth
- Edge
- Base
- Discharge
- Surrounding inflammation
- Duration

DIGITAL BODY MAP
----------------
The examiner can tap the digital body map to mark a finding.
Tapping an existing mark clears it.

CLINICAL NOTE
-------------
The Clinical Note records the actual examination findings.
Normal / absent findings are explicitly recorded when selected.
Untouched fields are recorded as "Not recorded".

The number and coordinates of body-map markings are reproduced in
the Clinical Note.
