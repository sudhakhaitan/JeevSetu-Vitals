JeevSetu AI — Neurological Examination

Dedicated examination module for trained nurse / ANM / clinician

Standalone field-trial build • No cranial nerve examination • No anatomical drawing • This form supports examination and documentation; it does not diagnose.

1. Immediate Neurological Warning Screen

Ask about sudden symptoms and observe the patient before routine examination. If a warning sign is present, do not delay urgent care to complete this form.
URGENT WARNING: One or more warning signs are marked “Yes”. Activate the local emergency/referral pathway immediately. Do not continue routine examination before urgent clinical assessment. This form is not a stroke diagnostic tool.
One or more warning-screen answers are unknown/unassessed. Clarify promptly. If an acute neurological event is suspected, seek urgent clinical assessment.

D. Detailed reflex examination (trained examiner)

Grade deep tendon reflexes consistently: 0 absent, 1+ reduced, 2+ expected/average, 3+ brisk, 4+ very brisk / clonus. Interpret in context and compare sides. “Not tested” is not normal.
